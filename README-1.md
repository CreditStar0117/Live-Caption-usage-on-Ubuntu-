# 🎙️ Live Caption on Ubuntu

A guide to using live captioning on Ubuntu Linux for real-time speech-to-text transcription, making audio and video content more accessible.

## 📌 Overview

Live Caption is an accessibility feature that converts spoken audio into readable text in real time.

This project explores how to enable, configure, and use live captions on Ubuntu for activities such as:

- 🎥 Watching videos and online content
- 💻 Attending virtual meetings
- 🎧 Listening to podcasts and audio
- 📚 Learning through online lectures
- ♿ Improving accessibility for people with hearing difficulties

## ✨ Features

- **Real-Time Captions:** Convert spoken audio into text.
- **Accessibility:** Make audio content easier to understand.
- **Ubuntu Compatibility:** Explore captioning solutions for Linux.
- **Simple Configuration:** Step-by-step setup instructions.
- **Multiple Use Cases:** Useful for education, meetings, and entertainment.

## 🖥️ System Requirements

- Ubuntu Linux (22.04 LTS, 24.04 LTS, or a compatible version)
- Working audio output
- Microphone (optional, depending on the captioning solution)
- Internet connection (if required by the selected tool)
- A supported browser or speech recognition application

## 🚀 Getting Started

### Step 1: Update Ubuntu

Open your terminal and run:

```bash
sudo apt update && sudo apt upgrade -y
```

### Step 2: Choose a Live Caption Solution

Ubuntu does not provide a universal built-in live captioning feature across all applications.

However, live captions can be accessed through supported applications and browsers.

One option is Google Chrome, which provides a built-in Live Caption feature for supported audio content.

### Step 3: Enable Live Caption in Google Chrome

1. Open Google Chrome.
2. Navigate to **Settings**.
3. Select **Accessibility**.
4. Find the **Live Caption** option.
5. Enable Live Caption.
6. Allow Chrome to download the required speech recognition files, if prompted.
7. Play supported audio or video content.

Captions should appear automatically when speech is detected in supported content.

## 📖 How to Use

1. Launch your chosen captioning application.
2. Enable its live captioning feature.
3. Start playing audio or video.
4. Observe the automatically generated captions.
5. Adjust available caption settings for better readability.

**Note:** Chrome's Live Caption feature does not provide system-wide captioning for every Ubuntu application.

## ⚠️ Limitations

- Caption accuracy depends on audio quality.
- Background noise may affect transcription.
- Supported languages vary by application.
- Some solutions require an internet connection.
- Browser-based captioning may not work with audio from other desktop applications.
